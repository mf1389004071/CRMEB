# 首页指定商品改价后价格不刷新

## 现象

后台/区域价改了商品售价后，移动端**商品详情**已是新价，**首页商品列表**仍是旧价。

## 根因

当前使用主题（生产 `eb_theme.id=1` 经典红）首页「商品列表」为**指定商品**（`typeConfig=1`）。装修保存时把当时的 `price` 整份写入 `eb_theme.home_data`。

- 首页：`theme_info/home` 原样返回 JSON → `goodList.vue` 直接渲染 `goodsList.list[].price`（快照）
- 详情：`product/detail` 读库 + 区域价，实时

生产核对（商品 5/6）：主题快照仍为 `45000` / `32000`，`eb_store_product.price` 已是 `92000` / `75000`。清 Redis 无效（首页不走区域价缓存）。

## 修复

1. **后端** `ThemeServices::getThemeInfo('home')`：对 `goodList`/`goodRecommend` 指定商品、以及 `promotionList` 手动选品，按 id 重查并 `applyToList` 区域价后再返回（不发版小程序也可生效）。
2. **前端** `goodList.vue`：`typeConfig==1` 时用 `getProductslist({ ids })` 拉实时价，不再用装修快照价。
3. **顺带** `StoreProductServices::getThemeProduct`：自定义组件商品接口补区域价。

## 上线

优先发 **PHP 后端**（`ThemeServices` / `StoreProductServices`）。小程序/H5 前端改动随下次发版带上即可。

## 临时运维手段（未发版前）

装修后台打开首页主题 → 商品列表组件重新保存一次，可把快照价写成当前主表价；有区域价差异时仍应以代码修复为准。
