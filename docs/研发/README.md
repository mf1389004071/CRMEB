# 研发文档

存放**代码调整 / 技术方案 / 前后端衔接分析**等研发过程文档。

## 目录约定（默认）

后续新增与「代码改动、实现分析、技术衔接」相关的 Markdown，**若无明确指定其它目录**，一律放在本目录 `docs/研发/`。

| 目录 | 用途 |
|------|------|
| `docs/研发/` | 代码调整、技术方案、衔接/分析类 md（**默认落点**） |
| `docs/deploy/` | 部署、本地环境、域名、队列/定时/长连接等运维向文档 |
| `docs/docker/` | 本地 Docker Compose 与镜像 |
| `docs/260409-菜集鲜/` 等专题目录 | 某需求/项目的需求、实现方案、设计（按专题归类） |
