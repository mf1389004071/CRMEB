# 币种与金额显示（菜集鲜 / 越南站）

本文汇总本位币、展示币、格式规则、前后端落点，以及与「界面语言」的关系。不含外部参考项目。

---

## 1. 核心原则

| 原则 | 说明 |
|------|------|
| 存储/结算只用本位币 | 区域价、订单应付、购物车合计一律存 **本位币**（预置 `VND`） |
| 展示币只在展示层 | 换算发生在前端 `$money` / `BaseMoney` 或后端 `MoneyServices::format`；不落多套区域价 |
| 合计先本位再换算 | 购物车/订单总价 = **本位币合计** 再换算；禁止对已换算行价求和（避免取整误差） |
| 非本位币加 `≈` | 展示币 ≠ 本位币时金额前缀 `≈`（如 `≈¥125.72`）；本位币不加 |
| 订单快照不回溯 | 下单写 `currency_code` / `exchange_rate` / `pay_amount_display`；事后改汇率不影响历史单 |
| 现场收款主看本位 | 管理端/打印单主金额用本位币；展示币仅作参考 |

## 2. 预置币种与格式（现行）

表：`eb_system_currency`（迁移 `crmeb/database/vn/060_currency.sql`，已装库千分位修正见 `061_currency_vnd_thousand_comma.sql`）。

| code | 符号 | 小数位 | 千分位 | 小数点 | 角色 | 示例 |
|------|------|--------|--------|--------|------|------|
| VND | ₫ | 0 | `,` | `.` | 本位币 | `₫449,000` |
| CNY | ¥ | 2 | `,` | `.` | 展示币 | `≈¥125.72` |
| USD | $ | 2 | `,` | `.` | 展示币 | `≈$17.96` |

汇率含义：**1 本位币 = rate 该币种**（示例汇率需上线前在后台校准）。

### 2.1 为什么 VND 用逗号千分位

- 越南本地存在两种习惯：公文/部分系统用点（`449.000`），**超市小票/收银 POS 常见逗号**（`449,000`）。
- 本站按现场小票习惯，VND 统一为 **`,` 千分位**；VND 日常无小数，与小数点不冲突。
- CNY/USD 同为 `,` 千分位 + `.` 小数，三币种展示分隔符一致，减少运营困惑。
- 后台「币种与汇率」仍可改某币种的 `thousand_sep` / `decimal_sep`，改后清缓存即生效。

### 2.2 格式跟语言吗？跟展示币吗？

**格式跟展示币种配置，不跟界面语言。**

- 切中文 / 越文 / 英文：只换文案与多语内容，**不会**自动改千分位或换成人民币。
- 语言（`locale` / `Cb-lang`）与展示币种（`display_currency` / `Cb-currency`）是两套设置。
- 要看人民币：用户须在「我的 → 展示币种」选 **CNY**（或解析链路落到 CNY），不是切成中文就会变。

## 3. 展示币种如何选定

后端 `MoneyServices::resolveDisplayCode()` 优先级：

1. 请求头 `Cb-currency`
2. 登录用户 `eb_user.display_currency`
3. 当前配送区域所属国家默认（`VN→VND`，`CN→CNY`）
4. 本位币

移动端：本地 `display_currency` 优先；启动拉 `GET api/public/currency` 写入列表与默认；切换时 `POST api/user/currency`。

管理端：**默认展示本位币**（收款/运营主看本位）；可用 `$money(amount, { code: 'CNY' })` 临时看折算。

## 4. 后端

| 能力 | 位置 |
|------|------|
| 换算 / 格式化 / 快照 / 解析展示码 | `crmeb/app/services/system/MoneyServices.php` |
| 后台 CRUD + 汇率日志 | `crmeb/app/services/vn/CurrencyAdminServices.php` |
| 管理接口 | `adminapi`：`setting/currency`（list/save/delete/logs） |
| H5 币种列表 | `GET api/public/currency` |
| 用户保存展示币 | `POST api/user/currency` |
| 数据 | `060_currency.sql`；千分位逗号修正 `061_currency_vnd_thousand_comma.sql` |
| 菜单 | `086_currency_menu.sql` |
| 单测 | `crmeb/tests/vn/currency_test.php` |

`MoneyServices::format($amount, $code, $withSymbol)`：按该币种小数位/千分位/符号输出；非本位加 `≈`。  
改币种后调用 `MoneyServices::flush()` 清缓存（后台保存已自动 flush）。

## 5. 移动端（uni-app）

| 能力 | 路径 |
|------|------|
| 格式化 / 换算 / 展示币状态 | `template/uni-app/utils/money.js` |
| 展示组件 | `template/uni-app/components/BaseMoney.vue` |
| 全局方法 | `main.js` → `Vue.prototype.$money = formatMoney` |
| VN 开关 | `template/uni-app/utils/vn.js` |
| 请求头 | `utils/request.js`：有展示币时带 `Cb-currency` |
| 设置入口 | `pages/users/user_info`：「展示币种」（`vnMode` 且多币种时） |
| 单测 | `template/uni-app/tests/money_test.js`（`node …/money_test.js`） |

约定：页面传入**本位币金额**，用 `$money(...)` 或 `<BaseMoney :money="..." />`，**不要手写 `¥`/`￥`/千分位**。  
仍有少量历史页残留硬编码符号（改价弹窗单位、部分 DIY 划线价等），主路径已接入。

## 6. 管理端（admin）

| 能力 | 路径 |
|------|------|
| 格式化（与移动端规则对齐） | `template/admin/src/utils/money.js` |
| 全局方法 | `main.js` → `this.$money` |
| 过滤器 | `filters/index.js` → `{{ amount \| money }}` |
| 启动拉取币种表 | `App.vue` → `loadCurrencyConfig()`（读 `setting/currency`） |
| 币种配置页 | `pages/setting/currency/index.vue`（保存/删除后刷新本地配置） |
| 已接入示例 | `pages/order/codPrint` 打印金额走 `$money` + 本位币 |

管理端展示用 `$money` / `money` 过滤器；录入用全局组件 `<MoneyInput>`（失焦千分位，聚焦可编辑纯数字，提交前为数值）。

已覆盖：商品列表/编辑规格价/会员价与返佣、区域价、订单列表/详情/退款/发货、COD 列表与收款弹窗、发票、财务流水/佣金/提现/充值等。客服端、短信套餐、装修预览若仍见 `¥`，按同样方式替换。百分比输入（折扣%）不走 MoneyInput。

用法示例：

```js
this.$money(449000);                    // ₫449,000（默认本位）
this.$money(449000, { code: 'CNY' });   // ≈¥…（按汇率）
this.$money(449000, { symbol: false }); // 449,000
```

```html
{{ row.pay_price | money }}
<MoneyInput v-model="form.price" />
```

## 7. 与多语言的关系（讨论结论）

| 问题 | 结论 |
|------|------|
| 千分位是否跟语言走？ | **否**，跟币种表字段 |
| 切中文是否自动显示人民币并换算？ | **否**；须展示币种为 CNY |
| 本位 VND 时 CNY 能否换算显示？ | **能**，选展示币 CNY 后展示层按 `rate` 换算并加 `≈` |
| 管理端主显示什么？ | **本位币**；展示币辅助 |

## 8. 运维与验收

1. 执行/确认 `061_currency_vnd_thousand_comma.sql`（已装库更新 VND 分隔符）。
2. 清后端缓存（`MoneyServices` 币种缓存约 10 分钟，或后台「清除缓存」/删 `runtime/cache`）。
3. H5：VND 价应显示 `₫449,000`；切展示币 USD（示例汇率 0.00004）→ `≈$17.96`。
4. 管理端币种页改千分位后，刷新页面，`$money` 应跟新配置。
5. 跑测：`node template/uni-app/tests/money_test.js`；`php crmeb/tests/vn/currency_test.php`（需测试库已更新 VND 分隔符）。

回滚 VND 分隔符（不推荐）：

```sql
UPDATE eb_system_currency SET thousand_sep='.', decimal_sep=',' WHERE code='VND';
```
