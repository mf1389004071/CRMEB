# 技术导入流程（客户不用看）

前提：库已跑过 VN 迁移（存在 `city_id=900002` 国家根、仓表、区域价表）。

## 一句话

客户填好两张 CSV → 你提供 MySQL → 一条命令导入 → `out/` 里留下可复跑的 SQL 备份。

```text
01_商品.csv ──导入──► DB 商品/规格
                         │
                    自动 SELECT 映射
                         ▼
02_城市仓价格.csv ──导入──► 区划 + 仓 + 区域价
                         │
                         ▼
              out/时间戳/*.sql 备份
```

**不再需要**客户或人工维护 `03_编码映射`。

## 安装

```powershell
pip install pymysql
```

## 命令

本地 Docker 默认（宿主机端口 33060）：

```powershell
cd docs\260409-菜集鲜\初始业务数据模板\tools

# 只生成 SQL、不写库（看结构）
python import_vn_init.py --mysql "mysql://root:root@127.0.0.1:33060/crmeb" --step all --dry-run

# 正式导入（商品→查库→城仓价），并备份 SQL
python import_vn_init.py --mysql "mysql://root:root@127.0.0.1:33060/crmeb" --step all

# 分步
python import_vn_init.py --mysql "mysql://root:root@127.0.0.1:33060/crmeb" --step products
python import_vn_init.py --mysql "mysql://root:root@127.0.0.1:33060/crmeb" --step regions
```

`--mysql` 换成你的库即可。备份默认写到 `../out/yyyyMMdd_HHmmss/`：

| 文件 | 内容 |
|------|------|
| `01_products.sql` | 分类/商品/规格 |
| `02_regions.sql` | 省/郡区划 |
| `02_warehouse.sql` | 提货仓与关联 |
| `03_region_price.sql` | 区域价 |
| `_sku_map_from_db.csv` | 本次从库查到的编码映射（内部用） |
| `00_report.md` | 摘要 |

## 脚本自动处理（客户不用填）

- 区划稳定键写入 `eb_system_city.area_code`（`VNINIT:…`）
- 仓编码 `WHINIT:…`
- 商品用 `keyword=VNSKU:编码` + `attr_value.bar_code` 找回
- 单规格「默认」；占位图可 `--image` 覆盖
- 河内/胡志明自动 `is_hot=1`
- `city_id` 默认从 `920001` 起分配（可用 `--city-id-base`）

## 导入后

1. 后台配送区域「重建 path」（或对应命令）
2. 清缓存
3. 确认 `vn_mode_enable` / `region_pricing_enable` / `offline_pay_status=1`
4. 冒烟：切城看价 → COD 下单 → 打印含仓

## 与旧方案差异

| 旧 | 现 |
|----|----|
| 客户填区划编码/仓编码/规格编码/划线/开关… | 客户只填业务字面量 |
| 人工 `03_编码映射.csv` | 导完 01 后脚本查库 |
| 先出 SQL 再手工执行 | 脚本直连执行 + 备份 SQL |
