# 初始业务数据（给客户填）

客户**只填两张极简表**，不用懂编码映射、区划 ID、规格 unique。

| 文件 | 填什么 |
|------|--------|
| [01_商品.csv](01_商品.csv) | 商品编码、名称、单位、参考价、库存 |
| [02_城市仓价格.csv](02_城市仓价格.csv) | 省、郡(可空)、仓名、仓地址、各商品在该城的价格 |

技术侧用 Python **直连数据库**导入：先导商品 → 自动查库得到 `product_id/unique` → 再导城/仓/区域价 → **备份本次 SQL** 到 `out/时间戳/`。无需、也不再提供 `03_编码映射`。

说明与命令见 [转换流程.md](转换流程.md)。

## 客户怎么填

### 01_商品.csv

```text
商品编码,商品名,单位,参考价,库存
POTATO,Khoai tây,kg,45000,500
```

- **商品编码**：英文大写短码（建议 ≤15 字符），后面价格列靠它对齐。
- 其余按字面填即可。不用填规格、分类、划线价。

### 02_城市仓价格.csv

```text
省,郡,仓名,仓地址,价_POTATO,价_ONION,...
Hà Nội,,Kho Hà Nội,"123 Đường Láng, Hà Nội",45000,32000
```

- **省**必填；**郡**可空（空=整省一个价/一个仓）。
- **仓名 / 仓地址**必填。
- 价格列名：`价_` + 商品编码（与 01 一致）。
- **单元格留空 = 该城不卖该品**；不要填 0。
- 新增商品：在 01 加一行，再在 02 加一列 `价_新编码`。
