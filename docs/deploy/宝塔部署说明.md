## 宝塔部署要点（PHP 7.4）

按 `系统安装流程文档` + `安装说明`：

1. 软件商店安装：**Nginx、MySQL 5.7/8.0、PHP 7.4、Redis**（建议）
2. 添加站点：域名 / 数据库；**网站根目录指到 `crmeb` 目录**，**运行目录设为 `/public`**
3. 伪静态选 **ThinkPHP**（或文档里那套 rewrite）
4. PHP 7.4 扩展：`fileinfo、pdo_mysql、openssl、mbstring、curl、redis、gd、zip、bcmath` 等
5. 上传限制建议：`upload_max_filesize/post_max_size` ≥ 100M，`memory_limit` ≥ 256M
6. 目录权限：`runtime`、`public/uploads` 可写（文档示例 `chmod 755`，Linux 常需 `www` 用户可写）
7. 浏览器打开域名走安装向导；装完可删/改名 `public/install/index.php`
8. 生产建议再配：消息队列、定时任务、长连接（Workerman + Nginx `/notice` `/msg`），详见 `docs/deploy/消息队列定时任务与长连接说明.md`

访问：后台 `域名/admin`，H5/首页 `域名/`。  
基线默认管理员：**账号 `admin` / 密码 `crmeb.com`**（安装向导若另行设置则以实际为准）。本地 Docker 同此默认值，见 `docs/deploy/本地开发环境搭建教程.md`。

**域名与静态图：** 若数据库来自本地 Docker 或安装包演示数据，库内可能仍是 `localhost:8089` / `demo.crmeb.com`。上线后**需要**改 `site_url` 并视情况批量替换 DIY/主题/商品中的绝对 URL，步骤见 `docs/deploy/站点域名与静态资源切换说明.md`。全新用正式域名走安装向导时，安装脚本会替换演示域名，仍建议装完自检。

## 前端怎么编译

### 管理端（`template/admin`）

```powershell
cd template\admin
npm install
# 生产 API：.env.production 里 VUE_APP_API_URL（同域非独立部署一般留空）
npm run build
```

- 产物：`template/admin/dist/`
- 部署：把 `dist` **整目录内容**拷到 `crmeb/public/admin/`（`vue.config.js` 里 `publicPath: '/admin'`；也可改 `outputDir` 直接打到 `../../crmeb/public/admin`）

实际脚本是 `npm run build`（不是文档里偶见的 `build:prod`）。

### 移动端（`template/uni-app`）

本项目更推荐 **HBuilderX**：

1. 用 HBuilderX 打开 `template/uni-app`
2. 改 `config/app.js` 里的 `HTTP_REQUEST_URL`（小程序/APP 必改；H5 同域可不改）
3. 发行：
   - **H5**：发行 → H5 → 产物拷到 `crmeb/public/`（覆盖/合并站点根静态）
   - **微信小程序**：发行 → 小程序-微信 → 用微信开发者工具上传

`package.json` 几乎无脚本依赖，CLI 的 `npm run build:h5` 在本仓库不一定开箱可用；以 HBuilderX 为准。有 CLI 环境时可参考 `help/dev-docs/uniapp/移动端前端架构说明.md`。
