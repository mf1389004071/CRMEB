# 菜集鲜（crmeb_cjx）本地开发环境搭建教程

> 日期：2026-10-24（更新：docker-compose + MySQL 任意来源可连）  
> 适用：Windows 11 + Docker Desktop + PowerShell（从零搭建）  
> 目标：本机启动开发环境，浏览器访问 `http://localhost:8089/`

推荐使用 **`docs/docker/docker-compose.yml`** 管理 `cjx-mysql` + `cjx-php`。  
**不是** `help/docker/docker-compose.yml` 那套官方编排（端口/容器名不同，勿混用）。

---

## 0. 环境一览

| 组件 | 说明 |
|------|------|
| 编排 | `docs/docker/docker-compose.yml`，网络 `cjx_net` |
| MySQL | 容器 `cjx-mysql`，镜像 `mysql:8.0`，宿主 **33060**→3306，数据卷 `cjx_mysql_data` |
| PHP | 容器 `cjx-php`，镜像 **`dev-php74`**（PHP 7.4.33），宿主 **8089** |
| 代码挂载 | `<repo>/crmeb` → `/app` |
| PHP 启服 | `php -S 0.0.0.0:8089 router.php`（工作目录 `/app/public`） |
| 库 / 账号 | 库 `crmeb`；**root/root**、**crmeb/root**（均 `mysql_native_password`，允许任意 host） |
| PHP→MySQL | compose 内主机名 **`mysql`**，端口 **3306**（同网络，不经宿主机映射） |
| 缓存 | 默认 file（可不启 Redis） |
| 站点 URL | `http://localhost:8089`（须写入 `site_url`） |

**访问：**

| 入口 | 地址 |
|------|------|
| H5 / 商城 | http://localhost:8089/ |
| 管理后台 | http://localhost:8089/admin/ |

**管理员登录（基线 SQL 默认，本地库已核对账号 `admin`）：**

| 项 | 值 |
|----|-----|
| 后台地址 | http://localhost:8089/admin/ |
| 账号 | `admin` |
| 密码 | `crmeb.com` |

若安装向导或后台改过密码，以实际为准；官方安装说明同上默认值（`help/resource/安装说明.md`）。

**数据库怎么连（任意方式）：**

| 场景 | Host | Port | User | Password |
|------|------|------|------|----------|
| 宿主机 Navicat / DBeaver / IDEA | `127.0.0.1` | `33060` | `root` 或 `crmeb` | `root` |
| PHP 容器内（compose） | `mysql` | `3306` | `root` | `root` |
| 其它容器加入 `cjx_net` | `cjx-mysql` 或 `mysql` | `3306` | `root` | `root` |

鉴权使用 **`mysql_native_password`**，避免 MySQL 8 默认 `caching_sha2_password` 导致客户端报：

```text
1045 - Access denied for user 'root'@'172.17.0.1' (using password: YES)
```

相关文件：

- `docs/docker/mysql/conf.d/cjx.cnf` — utf8mb4、native_password、空 sql_mode、bind 全网卡  
- `docs/docker/mysql/init/01-grant-any-host.sql` — **首次**空数据目录自动授权  
- `docs/docker/mysql/grant-any-host.sql` — **已有库**手动补授权（可重复执行）

## 1. 前置条件

```powershell
docker version
docker compose version
```

- 仓库根目录下文写作 `<repo>`，例如 `C:\data\code\crmeb\crmeb_cjx`  
- 后端在 `<repo>\crmeb`；缺 `vendor` 时见第 5.3 节  
- 端口 **33060、8089** 勿占用：

```powershell
netstat -ano | findstr "LISTENING" | findstr ":8089 :33060"
```

若以前用 `docker run` 起过同名容器，先停掉再改用 compose：

```powershell
docker rm -f cjx-php cjx-mysql
```

（数据在匿名卷里时，迁移方法见第 10 节。）

## 2. 一键启动（推荐）

在**仓库根目录**：

```powershell
cd <repo>
docker compose -f docs/docker/docker-compose.yml up -d --build
```

首次会构建 `dev-php74`、拉 `mysql:8.0`、创建卷并启动。MySQL healthy 后才会起 PHP。

```powershell
docker compose -f docs/docker/docker-compose.yml ps
Invoke-WebRequest -Uri "http://localhost:8089/" -UseBasicParsing | Select-Object StatusCode
# 期望 200（若尚未导库/无 install.lock，可能进安装页或报错，继续第 4～6 节）
```

日常：

```powershell
docker compose -f docs/docker/docker-compose.yml start
docker compose -f docs/docker/docker-compose.yml stop
docker compose -f docs/docker/docker-compose.yml logs -f php
# down 不删库数据；down -v 会删 cjx_mysql_data，慎用
docker compose -f docs/docker/docker-compose.yml down
```

更短说明见 [`docs/docker/README.md`](../docker/README.md)。

## 3. 仅构建 PHP 镜像（可选）

compose 的 `php.build` 已指向 `docs/docker/dev-php74.Dockerfile`。也可单独构建：

```powershell
cd <repo>
docker build -t dev-php74 -f docs/docker/dev-php74.Dockerfile .
docker run --rm dev-php74 php -v

```

## 4. 导入基线库 + vn 迁移

**空库**（compose 首次初始化）只有空的 `crmeb` 库，需导入业务数据。

### 4.1 基线（勿改文件）

```powershell
docker cp <repo>\crmeb\public\install\crmeb.sql cjx-mysql:/tmp/crmeb.sql
docker exec cjx-mysql mysql -uroot -proot --default-character-set=utf8mb4 crmeb -e "source /tmp/crmeb.sql"
```

```powershell
docker exec cjx-mysql mysql -uroot -proot -N crmeb -e "SELECT COUNT(*) FROM information_schema.tables WHERE table_schema='crmeb';"
```

### 4.2 `crmeb/database/vn/*.sql` 按文件名排序执行

约定见 `crmeb/database/vn/README.md`（须先 `000_helpers.sql`）。

推荐一键（UTF-8 读文件 + utf8mb4 客户端，含 demo 导入后「?」自检）：

```powershell
powershell -File crmeb/database/vn/run_all.ps1
```

手工按文件执行时**必须**带 `--default-character-set=utf8mb4`（漏掉会导致中/越文入库变成字面量 `?`）：

```powershell
$files = Get-ChildItem "<repo>\crmeb\database\vn\*.sql" | Sort-Object Name
foreach ($f in $files) {
  Write-Host ">>> $($f.Name)"
  docker cp $f.FullName "cjx-mysql:/tmp/$($f.Name)"
  docker exec cjx-mysql mysql -uroot -proot --default-character-set=utf8mb4 crmeb -e "source /tmp/$($f.Name)"
}
# 演示数据（可选）
docker cp "<repo>\crmeb\database\vn\demo\001_demo_data.sql" cjx-mysql:/tmp/001_demo_data.sql
docker exec cjx-mysql mysql -uroot -proot --default-character-set=utf8mb4 crmeb -e "source /tmp/001_demo_data.sql"
```

序号族：`000 → 001 → 010 → 020 → 021 → 030 → 040 → 050 → 051 → 060 → 070 → 080～087 → 090 → 091 → 900`。  
**勿对生产库执行。**

### 4.3 确认账号插件（防 1045）

首次 init 脚本会授权；若仍 1045 或从旧卷迁来，再执行：

```powershell
docker cp <repo>\docs\docker\mysql\grant-any-host.sql cjx-mysql:/tmp/grant-any-host.sql
docker exec cjx-mysql mysql -uroot -proot --default-character-set=utf8mb4 -e "source /tmp/grant-any-host.sql"
```

期望输出含：

```text
root   %           mysql_native_password
root   localhost   mysql_native_password
crmeb  %           mysql_native_password
```

## 5. `.env`、`install.lock`、Composer

### 5.1 `crmeb/.env`（与 compose 一致）

compose 已注入 `DATABASE_*`；写 `.env` 更直观。**主机名用服务名 `mysql`，端口 `3306`：**

```ini
APP_DEBUG = true

[APP]
DEFAULT_TIMEZONE = Asia/Shanghai

[DATABASE]
TYPE = mysql
HOSTNAME = mysql
HOSTPORT = 3306
USERNAME = root
PASSWORD = root
DATABASE = crmeb
PREFIX = eb_
CHARSET = utf8mb4
DEBUG = true

[LANG]
default_lang = zh-cn

[CACHE]
DRIVER = file
CACHE_PREFIX =
CACHE_TAG_PREFIX =

[REDIS]
REDIS_HOSTNAME = 127.0.0.1
PORT = 6379
REDIS_PASSWORD =
SELECT = 0

[QUEUE]
QUEUE_NAME =
```

注意：

- **不要**在 PHP 容器里写 `127.0.0.1:33060`（那是宿主机视角）。  
- 若不用 compose、PHP 仍走 `host.docker.internal:33060`，见文末「旧 docker run 方式」。  
- `.env` 一般不入库。

### 5.2 `install.lock`

```powershell
Set-Content -Path "<repo>\crmeb\public\install.lock" -Value "1" -NoNewline
```

### 5.3 Composer（缺 vendor 时）

```powershell
docker run --rm -v C:/data/code/crmeb/crmeb_cjx/crmeb:/app -w /app dev-php74 composer install --no-interaction
```

## 9. 常见问题

| 现象 | 处理 |
|------|------|
| **1045 Access denied … 172.17.0.1** | 执行第 4.3 节 `grant-any-host.sql`；客户端用 `127.0.0.1:33060` + root/root；确认 `plugin=mysql_native_password` |
| Navicat 连不上 / Public Key Retrieval | 换 native_password（上条）；或客户端勾选允许公钥检索（治标） |
| 打开安装页 | 补 `install.lock` |
| PHP 报连不上库 | `.env` / 环境变量应为 `HOSTNAME=mysql`、`HOSTPORT=3306`（compose 内） |
| 图片仍是 demo.crmeb.com | 第 6 节域名切换 + 清缓存 |
| 后台提示队列/定时/长连接未开 | 见 [`消息队列定时任务与长连接说明.md`](./消息队列定时任务与长连接说明.md)；纯接口联调可暂忽略 |
| 8089/33060 冲突 | 改 `docs/docker/docker-compose.yml` 端口映射，并同步 `site_url` |
| conf.d 被 ignore（world-writable） | compose 已用 `configs` + mode 0444；关键参数也在 `command:` 里写死 |

## 10. 从旧 `docker run` 迁到 compose

旧 `cjx-mysql` 匿名卷若仍在：

```powershell
docker volume ls
# 找到含 crmeb 数据目录的卷名 OLD_VOL
docker compose -f docs/docker/docker-compose.yml stop
docker run --rm -v OLD_VOL:/from -v cjx_mysql_data:/to alpine sh -c "find /to -mindepth 1 -maxdepth 1 -exec rm -rf {} +; cp -a /from/. /to/"
docker compose -f docs/docker/docker-compose.yml up -d
# 再执行 grant-any-host.sql
```

## 12. 从零最短路径

1. 安装 Docker Desktop  
2. `docker compose -f docs/docker/docker-compose.yml up -d --build`  
3. 导入 `crmeb.sql` → 执行 `database/vn/*.sql` → 必要时跑 `grant-any-host.sql`  
4. 写好 `crmeb/.env`（`mysql:3306`），创建 `install.lock`  
5. 修正 `site_url` 与演示站绝对 URL → 清缓存  
6. 打开 http://localhost:8089/ ；后台 http://localhost:8089/admin/ （账号 `admin` / 密码 `crmeb.com`）

## 附录：旧版分别 `docker run`（不推荐）

仅当无法使用 compose 时：

```powershell
docker run -d --name cjx-mysql `
  -e MYSQL_ROOT_PASSWORD=root -e MYSQL_DATABASE=crmeb `
  -p 33060:3306 `
  -v cjx_mysql_data:/var/lib/mysql `
  mysql:8.0 `
  --character-set-server=utf8mb4 `
  --default-authentication-plugin=mysql_native_password `
  --sql-mode= `
  --bind-address=0.0.0.0

docker run -d --name cjx-php `
  --add-host=host.docker.internal:host-gateway `
  -p 8089:8089 `
  -v C:/data/code/crmeb/crmeb_cjx/crmeb:/app `
  -w /app/public `
  -e DATABASE_HOSTNAME=host.docker.internal `
  -e DATABASE_HOSTPORT=33060 `
  -e DATABASE_DATABASE=crmeb `
  -e DATABASE_USERNAME=root `
  -e DATABASE_PASSWORD=root `
  -e DATABASE_CHARSET=utf8mb4 `
  dev-php74 php -S 0.0.0.0:8089 router.php
```

此方式下 `.env` 的 `HOSTNAME` 应为 `host.docker.internal`，`HOSTPORT` 为 `33060`。导库后务必执行 `grant-any-host.sql`。
